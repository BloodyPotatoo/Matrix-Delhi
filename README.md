# Image Editor Website

A powerful, browser-based image editor designed to make professional editing fast, simple, and accessible without installing software.

## Key Features

* **Image Upload** — Import JPG, PNG, WebP, and other common image formats directly into the editor.
* **Canvas Editor** — Edit images on a flexible, interactive canvas with real-time previews.
* **Crop & Resize** — Crop images precisely and change their dimensions or aspect ratio.
* **Rotate & Flip** — Rotate images and flip them horizontally or vertically.
* **Filters & Adjustments** — Control brightness, contrast, saturation, exposure, blur, grayscale, and other visual properties.
* **Drawing Tools** — Draw freely using adjustable brush size, opacity, and colors.
* **Text Tool** — Add customizable text with different fonts, sizes, colors, alignment, and positioning.
* **Shapes** — Add basic shapes such as rectangles, circles, lines, and arrows.
* **Layers** — Organize different elements independently and move, hide, or modify them without affecting the rest of the design.
* **Undo & Redo** — Quickly reverse or restore editing actions.
* **Zoom & Pan** — Work comfortably on detailed areas of an image.
* **Background Editing** — Modify or remove backgrounds for cleaner compositions.
* **Drag & Drop** — Easily add images and elements directly onto the canvas.
* **Keyboard Shortcuts** — Speed up editing with shortcuts for common actions.
* **Export** — Download finished projects in formats such as PNG and JPEG.
* **Responsive Interface** — Designed to work across desktops, laptops, tablets, and different screen sizes.
* **Browser-Based** — No installation required; editing happens directly in the web browser.
* **Modern UI** — Clean, intuitive interface inspired by professional creative tools while remaining beginner-friendly.
* **Privacy-Focused Editing** — Images can be processed locally in the browser, minimizing the need to upload personal images to a server.
